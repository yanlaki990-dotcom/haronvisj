# HaronVisuals Client

Приватный клиент Minecraft 1.21.4 на Fabric.

## Состав

| Файл | Описание |
|------|----------|
| `haron-1.1-SNAPSHOT-obf.jar` | Основной клиент HaronVisuals (obfuscated) |
| `fabric-api-0.119.4-1.21.4.jar` | Fabric API для Minecraft 1.21.4 |

## Установка

1. Установи Minecraft 1.21.4 с Fabric Loader.
2. Скопируй оба `.jar`-файла в папку `mods` (обычно `%APPDATA%\.minecraft\mods`).
3. Запусти игру с профилем Fabric.

## Скачивание

Файлы доступны в разделе [Releases](../../releases) репозитория.
